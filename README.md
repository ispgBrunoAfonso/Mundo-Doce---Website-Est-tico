# 🍰 Mundo Doce --- Website Estático

Bem-vindo ao repositório do website da **Mundo Doce**, uma confeitaria e pastelaria tradicional focada em trazer doçura e momentos felizes à vida dos nossos clientes! Este é um website estático, moderno e totalmente responsivo.

---

## 🚀 Funcionalidades do Website

O site foi estruturado para guiar o cliente através de uma experiência visual deliciosa, incluindo as seguintes secções:
* **Página Inicial**
* **Sobre nós**
* **Especialidades**
* **Avaliações**
* **Horário**
* **Fale Connosco**

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as tecnologias web fundamentais:
* **HTML5:** Para a estruturação limpa e semântica do conteúdo.
* **CSS:** Para a estilização, cores, tipografia e garantir que o site se adapta a telemóveis e computadores (Responsividade).

---

## 📸 Demonstração

O design do site inclui imagens representativas dos nossos produtos, com destaque para a identidade visual da marca (como o logótipo `MundoDoce.png`).
